# YIWU — Form Discovery Atlas

Documentation website for the Yiwu Twin Towers design process (SCI-Arc FA 2026 Vertical Studio).

- `index.html` — main node diagram (entry point / GitHub Pages root)
- `pages/` — linked documentation pages (brief, site analysis, platform city, programme, city assembly)
- `assets/css/yiwu.css` — shared style tokens (font, light ground, accents)
- `assets/fonts/` — local font (not committed, see .gitignore)

Open `index.html` in a browser, or serve the folder: `python -m http.server`.
